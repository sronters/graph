# GraphTrust NSRI submission package

## Primary submission files

- `pdf/GraphTrust_NSRI_Research_Brief.pdf` — four-page formatted submission:
  three-page Research Brief plus references, AI transparency, and reproducibility.
- `pdf/GraphTrust_Publication_Figures.pdf` — seven-page appendix containing all
  14 publication figures.
- `GraphTrust_NSRI_Research_Brief.tex` — editable LaTeX source.
- `GraphTrust_Submission_Source.zip` — paper source, figures, generated metrics,
  core research documentation, execution configs, and verification workflow.
- `GraphTrust_Colab_Notebooks.zip` — generic workflow plus three profile-specific
  high-memory notebooks.
- `GraphTrust_Figures.zip` — all SVG and 300-dpi PNG figures.
