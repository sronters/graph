# GraphTrust documentation

- [`deliverables/`](deliverables/) — final PDFs ready for review or submission.
- [`paper/`](paper/) — canonical editable LaTeX, generated metrics, and figures.
- [`evidence/`](evidence/) — committed CSV evidence, manifests, and statistical summaries.
- [`final_scientific_conclusions.md`](final_scientific_conclusions.md) — bounded conclusions supported by the evidence.
- [`final_experiment_matrix.md`](final_experiment_matrix.md) — completed and pending experiments.
- [`verification_status.md`](verification_status.md) — integrity and execution ledger.
- [`reproducibility.md`](reproducibility.md) — commands needed to reproduce the work.

The source code remains in `graphtrust/`, automated checks in `tests/`, and
reproducible experiment entry points in `scripts/`.
