# AI Use Transparency Statement

OpenAI Codex was used to interpret the engineering specification, create and revise code and documentation, run local tests, inspect the built interface in a browser, and diagnose failures. Research claims in the documentation were checked against the cited primary or official sources. Synthetic data are produced by deterministic repository code rather than edited to obtain favorable results. Reported metrics must come from saved experiment artifacts with dataset, configuration, environment, and checksum manifests.

At the time this statement was written, Codex had executed automated unit,
property, integration, API, frontend accessibility, build, static-type,
formatting, and lint checks. It completed and checksum-verified the entire
225-run small-scale confirmatory matrix, executed counterfactual remediation
verification, generated analysis tables and 14 publication figures, and
compiled and visually checked the LaTeX brief and figure appendix. The 225-run
medium extension and three large Colab notebooks were not completed in an
authenticated high-memory runtime and are not claimed as results. Docker
definitions and CI verification were prepared, but no Docker engine was
available for an actual image-build/startup test. No claim is made that a
human manually wrote all code or completed verification steps not evidenced by
the repository history and artifacts. The submitting author remains
responsible for understanding the method, checking citations and representative
findings, and accepting the final submission.
