# Research evidence

`cloud/` contains the strict 15-organization follow-up: raw depth and
remediation CSVs, their SHA-256 manifest, clustered statistics, and data-backed
figures. `evidence_manifest.csv` is generated from immutable run directories;
the checked-in root file is a compact provenance export, while
`cloud/evidence_manifest.json` is the complete manifest for the replicated
follow-up. Missing rows must never be replaced with synthetic identifiers.
