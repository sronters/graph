# GraphTrust research paper

This directory is the canonical editable source for the paper and publication figures.
Build the final PDFs with:

```bash
make -C docs/paper
```

The PDFs are written to `docs/deliverables/`. The main research brief ends before
the forced page break preceding references. References, the AI Use Transparency
Statement, and the reproducibility appendix are excluded from the NSRI 2–5 page
brief limit.
